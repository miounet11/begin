# 例子：短需求长什么样

服从 FAMILY.md · 角色：例子，不是现行产品合同。

合格的短需求只描述用户完成的事：

> 用户交一份原创乐谱规格，得到一首能播的歌，同一份谱可换模型重演。

由此推出的合同字段（示范，须进那个产品自己的仓）：

- 北极星：作品的权威在词曲谱；模型可替换；主路径能播。
- 主柱：谱对 / 能播 / 换模型重演。产品力 = min。
- 本季度不做：全端客户端、会员、商店、复刻受版权保护的词曲。
- 级别：L0，升级到期日由 owner 填。

不合格：把「Win + Mac + iOS + Android + 会员 + 100% 复刻竞品」写进做成。那是通道愿望，不是做成。
