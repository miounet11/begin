# 竞品扫描

服从 FAMILY.md · 角色：模板，复制进产品仓填写。

目标：从竞品提取用户 job、主路径、质量底线，服务北极星和门禁，不是做复刻清单。

禁止（见 [AGENTS.md](../AGENTS.md) 禁止清单）：

- 1:1 复刻受版权保护的词曲、旋律、UI 资产、源码
- 「100% 复刻」「因为竞品有所以我们做」
- 把竞品功能矩阵当作北极星

权威：[ship-standard COMPOUND-1](https://github.com/miounet11/ship-standard)（每项工作服务北极星）、[COMPOUND-6](https://github.com/miounet11/ship-standard)（本季度不做写下来）、[creativity-is-engineering](https://github.com/miounet11/creativity-is-engineering)（洞察不是定律，直到有稳定 id）。

## 竞品表（2–3 个，不超过 5 个）

| 竞品 | 用户 job（一句话） | 主路径（入口 → 提交 → 等待 → 完成） | 我们学到什么（门禁 / 不变量） | 我们不抄什么 | 证据 URL |
|------|-------------------|-------------------------------------|------------------------------|--------------|----------|
| | | | | | |
| | | | | | |
| | | | | | |

填写指南：

- **用户 job**：用户雇这个产品来完成什么事（不是产品功能）
- **主路径**：用户从打开到完成的最短路径，写成 4 步以内
- **学到什么**：可以变成门禁或不变量的东西（如「主路径必须 < 3 步」「失败时必须告知原因」）
- **不抄什么**：明确排除的功能、交互、商业模式
- **证据 URL**：公开可访问的链接（官网、产品页、App Store）

## 常见错误

| 错误 | 修法 |
|------|------|
| 列了 10 个竞品 | 只选 2–3 个最相关的 |
| 用户 job 写成产品功能 | 改成「用户完成 X」 |
| 主路径写成功能清单 | 改成 4 步以内的路径 |
| 「学到什么」写成「抄这个功能」 | 改成门禁或不变量 |
| 「不抄什么」是空的 | 每个竞品至少写一条不抄的 |
| 没有证据 URL | 补上，方便下一会话验证 |
